# 🐉 Skyrim Modlist — Experiência Definitiva

Uma modlist cuidadosamente selecionada para transformar **The Elder Scrolls V: Skyrim** em uma experiência moderna, imersiva e desafiadora.

---

## 📌 Sobre o Projeto

Esta modlist tem como objetivo:

- 🎨 Melhorar gráficos (texturas, iluminação, clima)
- ⚔️ Aprimorar gameplay (combate, IA, progressão)
- 🐛 Corrigir bugs do jogo original
- 🌍 Aumentar imersão e realismo

> Ideal para quem quer jogar Skyrim com qualidade atual sem perder a essência.

---

## ⚙️ Requisitos

Antes de instalar, você precisa de:

- Skyrim Special Edition (ou Anniversary Edition)
- PC com pelo menos:
  - 8GB RAM (recomendado: 16GB)
  - SSD (altamente recomendado)
  - GPU dedicada

---

## 📥 Instalação

### 1. Ferramentas necessárias

- Mod Organizer 2
- LOOT (Load Order Optimization Tool)
- SKSE (Skyrim Script Extender)
